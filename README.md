# DroidDeck

**Android Type-C 有线极速投屏 & 网页可视化键鼠映射中心**（针对小米 / HyperOS 深度适配与稳定性调优）。

无需在手机端安装任何第三方 App，一根 Type-C 转 USB 数据线直连电脑，即可在浏览器中使用 GPU 硬件加速解码实时投屏、多指并发游戏键鼠映射，或一键拉起原生 120FPS 独立窗口。

---

## ✨ 核心特性

- **零第三方 NPM 依赖**：纯 Node.js 原生 `http` + 内置 RFC 6455 WebSocket 服务端，轻量启动即用。
- **超低延迟有线推流与硬件解码**：
  - 服务端直连 Scrcpy (`scrcpy-server`) 底层协议，通过 ADB 隧道转发 H.264 视频流，支持 `i-frame-interval=1` 秒级关键帧恢复与自适应横竖屏分辨率切换。
  - 前端基于浏览器 **WebCodecs (`VideoDecoder`)** GPU 硬件加速解码渲染，支持 60 / 90 / 120 FPS 与最高 24 Mbps 码率选择。
- **多指并发游戏键鼠映射（Keymapper）**：
  - 通过 Scrcpy 32 字节二进制控制通道（`< 2ms` 延迟）注入独立触控指针 ID，支持多指并发操作不抢点：
    - `W / A / S / D`：8 方向平滑虚拟摇杆
    - `` ` ``（波浪键）：`PointerLock` 锁定鼠标实现 360° 准星视角转动（带屏幕边缘自动回中）
    - 任意键盘按键 & 鼠标左右键映射技能/开火/开镜/跳跃
  - 内置 **MOBA（王者荣耀 / LOL 手游）**、**FPS 射击（和平精英 / 暗区突围）**、**动作开放世界（原神 / 鸣潮 / 绝区零）** 三套预设。
  - 支持 **🛠️ 键位可视化编辑**：直接在投屏画面上拖拽调整图标位置、点击图标绑定键盘/鼠标按键、右键删除并保存到本地。
- **双引擎与实用设备控制**：
  - 支持一键拉起 **原生 Scrcpy SDL3 独立窗口（含手机音频转发）** 以及 **OTG HID 硬件键鼠模式**。
  - 支持 **手机熄屏投屏**（手机黑屏降发热，电脑端继续玩）、**原画无损 PNG 截图**、系统导航键（返回/桌面/多任务/音量/电源）。
- **Windows USB 断流抗干扰调优**：
  - 针对 Windows 11 + ADB v37 常见的 `failed to get feature set` 与 `LIBUSB_ERROR_PIPE` 断连问题，内置 `ADB_LIBUSB=1` + `ADB_BURST_MODE=0` 强制配置、断线自动重连以及一键重置 ADB 按钮。

## 🚀 快速开始

### 环境要求
- **系统**：Windows 10 / 11
- **运行环境**：[Node.js](https://nodejs.org/)（建议 v18+）
- **浏览器**：Chrome / Microsoft Edge（需支持 WebCodecs API）
- **连接线**：支持数据传输的 Type-C 转 USB / Type-C 数据线

### 安装与启动

```bash
# 1. 克隆仓库
git clone https://github.com/Yulia2233/DroidDeck.git
cd DroidDeck

# 2. 自动下载配置 Scrcpy + ADB 核心组件到 bin/scrcpy/
npm run setup

# 3. 启动服务
npm start
```

> 💡 **Windows 一键启动**：你也可以直接双击根目录下的 `启动投屏.bat`，首次运行会自动下载 `scrcpy` 与 `adb` 并自动打开浏览器控制台 **`http://localhost:3080`**。

## 📱 手机端设置（以小米 / 澎湃 HyperOS 为例）

首次使用 Type-C 连接电脑时，在手机上完成以下 3 步（之后插线即连）：

1. **开启开发者选项**：打开手机 `设置 → 我的设备 → 全部参数与信息`，连续点击 7 次 **`OS 版本`**（其他安卓品牌连续点击 `版本号`）。
2. **开启 USB 调试**：进入 `设置 → 更多设置 → 开发者选项`，打开 **「USB 调试」**，在手机弹窗勾选「始终允许使用这台计算机进行调试」并确定。
3. **【关键】开启安全设置**：在开发者选项中继续往下滑，打开 **「USB 调试（安全设置）」**。
   - *说明：小米 / HyperOS 必须开启此选项，才允许电脑通过鼠标点击屏幕和执行游戏键鼠映射；若暂不方便开启，可使用界面上的 **「🔌 OTG 模式」**。*

## 🎮 操控模式说明

在左侧面板顶部可随时切换 3 种模式：

| 模式 | 说明 |
| :--- | :--- |
| **🖱️ 鼠标触控** | 普通鼠标点击、拖拽滑动、滚轮上下滚动日常操作手机 |
| **🎮 键鼠映射激活** | 启用 `WASD` 摇杆、键盘/鼠标技能键及 `` ` `` 键锁定鼠标 360° 准星视角 |
| **🛠️ 键位可视化编辑** | 在画面上拖拽调整各按键坐标，单击图标重新绑定按键，右键删除，点击保存生效 |

## 🔧 常见断流 / 卡顿排查

1. **经常隔几十秒卡顿 2~3 秒后画面刷新，或偶发 `failed to get feature set`**：
   - **优先插主板后置原生 USB 3.x / Type-C 接口**：部分前置面板或 USB 2.0 分线器/扩展坞供电或信号不稳定，在持续高码率推流时容易触发物理断连重置。
   - **关闭 Windows USB 选择性暂停**：打开 `控制面板 → 电源选项 → 更改计划设置 → 更改高级电源设置 → USB 设置 → USB 选择性暂停设置`，将其设置为 **「已禁用」**。
   - **使用内置重置**：若出现 ADB 识别异常，可点击界面快捷栏的 **「🔄 重置ADB」** 按钮。
2. **能看到画面但鼠标点不动**：
   - 请确认手机开发者选项中的 **「USB 调试（安全设置）」** 已开启（小米/Redmi 机型必开）。
